Import passwords

Bring the passwords saved in your browser (or another password manager) into storii. Browsers don’t let extensions read their passwords, so you export them to a file first and choose it here. The file is read in this tab only; nothing but the encrypted vault leaves your computer.

storii is locked. Unlock it, then come back to this tab.

1. Export from your browser

Zen and Firefox
  1. Type about:logins in the address bar and press Enter (in Zen also Settings › Privacy & Security › Saved Passwords).
  2. Click ⋯ at the top right, then Export Passwords…, and confirm with your computer’s password.
  3. Save the file (logins.csv).
Chrome, Brave and Google Password Manager
  1. Open chrome://password-manager/settings (Brave: brave://password-manager/settings), or passwords.google.com › ⚙.
  2. Export passwords › Download file, and confirm with your computer’s password.
Edge
  1. Open edge://wallet/passwords.
  2. Click ⋯ next to “Saved passwords”, then Export passwords.
Safari and the Passwords app (Mac)
  1. In the Passwords app: File › Export All Passwords to File… (or Safari › File › Export › Passwords).

CSV exports from Bitwarden and 1Password work too. For their full exports (2FA codes, cards, passkeys) use the storii CLI or Android app.

2. Choose the file

    Now delete the file

    The export holds all your passwords unencrypted: delete it (and empty the trash).

    And stop the browser from saving passwords

    So the browser and storii don’t both offer to save, turn off the browser’s own password saving: Zen and Firefox: Settings › Privacy & Security › “Ask to save passwords”. Chrome and Brave: Google Password Manager › Settings › “Offer to save passwords”. Edge: Settings › Passwords › “Offer to save passwords”. Once you’ve checked that storii has everything, you can delete the passwords from the browser too.
